**FIOS** es un Sistema Operativo Financiero Personal diseñado para transformar la aburrida tarea de registrar gastos en una experiencia de gestión de infraestructura de alto nivel. Inspirado en terminales Linux, dashboards DevOps y herramientas de productividad modernas.

---

## 🚀 Visión del Sistema
A diferencia de las aplicaciones tradicionales, FIOS trata tus finanzas como recursos de hardware:
- **Ingresos** = RAM (Memoria Disponible)
- **Gastos** = CPU Load (Carga de Sistema)
- **Ahorros** = Vault (Almacenamiento Cifrado)

## ✨ Características Principales

### 📟 Centro de Operaciones (Ops)
Monitoriza la salud de tu sistema en tiempo real. Visualiza tu balance neto, estabilidad de red y telemetría de activos combinados.

### 📊 Motor de Smart Insights
Análisis local (100% offline) que detecta anomalías, calcula tu **Health Score** y predice la **Autonomía de Energía** (cuántos días de operación te quedan según tus hábitos).

### 🛡️ Protocolos de Seguridad
- **Modo Incógnito**: Cifrado visual de montos en toda la interfaz con un solo toque.
- **Bóveda (Vault)**: Almacenamiento seguro para activos fuera de línea con niveles de cifrado simulados.
- **Root Protection**: Confirmación de desasignación de datos (borrado seguro).

### 🤖 Automatización (Cron Jobs)
Programa tareas recurrentes de inyección de logs (pagos mensuales) para que el sistema se mantenga actualizado automáticamente.

### 🎨 Custom Kernels (Temas)
Personaliza tu entorno de escritorio con múltiples temas:
- **Hacker Green** (Default)
- **Matrix**
- **Kali Purple**
- **Nord**
- **Dracula**
- **Cyber Blue**

## 🛠️ Stack Tecnológico
- **UI**: Jetpack Compose (Material 3)
- **Lenguaje**: Kotlin + Coroutines + Flow
- **Base de Datos**: Room Persistence Library
- **Persistencia de Ajustes**: DataStore
- **Arquitectura**: Clean Architecture + MVVM + Manual DI (AppContainer)
- **Build System**: Gradle 8.7.3 + KSP

---

## ⚙️ Instalación y Compilación
1. Clonar el repositorio: `git clone https://github.com/bot-collab/fios.git`
2. Abrir en **Android Studio Ladybug (o superior)**.
3. Ejecutar `Sync Project with Gradle Files`.
4. El sistema requiere un dispositivo con **minSdk 26** y **targetSdk 35**.

---

## 📋 Protocolo de Datos
FIOS se rige bajo la filosofía **"Privacy First"**:
- **0 APIs externas**.
- **0 Analytics/Tracking**.
- **0 Servidores**.
Todo el procesamiento y almacenamiento ocurre exclusivamente en el dispositivo del Operador.
